# MR-102 — Save and reuse meeting presets

**Product:** Meeting Room
**Type:** Feature
**Status:** Planned
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** Medium

## Observed
Recurring meeting setup should be reusable instead of configured each time.

## Why it matters
Recurring teams should not rebuild the same permissions and setup for every session.

## Expected
Let users save named meeting presets by use case and apply them when creating new sessions, while still allowing per-session overrides.

## HighLevel response
HighLevel plans different presets based on meeting type/use case.
