# MR-120 — Platform-wide Translation & Label Manager

**Product:** Meeting Room  
**Type:** Platform  
**Status:** Planned
**Origin:** Direct request by Ivo in the 2026-04-14 HighLevel Product Town Hall; reiterated 2026-05-22.


## Observed
Translation/custom-label controls are implemented feature by feature.

## Why it matters
This creates repeated development work and prevents agencies from consistently localizing/renaming client-facing UI.

## Expected
One searchable platform string catalog with Agency → Location → asset overrides, import/export, bulk AI translation, missing-key view and reset-to-default.

## HighLevel response
On 2026-04-14, HighLevel said language translation support would come soon. As of the 2026-09-25 documentation check, Community tab names can be renamed manually, but automatic translation and a platform-wide label manager are not verified.
