# MR-101 — Create and select meetings inline from other product areas

**Product:** Platform
**Type:** Feature
**Status:** Planned
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** High

## Observed
From Calendars, Courses, Events, or Funnels, users should select/create/edit a meeting without leaving the current flow, with a link to the full manager.

## Why it matters
Inline management removes context switching and duplicated configuration across HighLevel products.

## Expected
From Calendars, Courses, Communities, Events, and Webinar/Funnel setup, allow Select existing / Create / Edit inline plus a link to open the full Meeting Room manager.

## HighLevel response
Inline Meeting Room integrations are the direction; the team targeted this flow for the following week.
