# MR-004 — Configure participant join modes per meeting

**Product:** Meeting Room
**Type:** Access
**Status:** Shipped
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** Medium

## Observed
Different meetings need different participant access modes.

## Why it matters
Different meetings need different privacy and friction levels; configurable entry avoids external workarounds.

## Expected
Let the host configure how participants access each meeting.

## HighLevel response
HighLevel confirmed this is configurable per meeting today: the host can control participant access. The team will continue expanding these options with Room/Session configuration. The currently requested behavior is shipped; keep outside Active.
