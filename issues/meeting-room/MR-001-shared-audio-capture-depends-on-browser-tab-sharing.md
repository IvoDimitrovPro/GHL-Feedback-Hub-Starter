# MR-001 — Shared audio capture depends on browser-tab sharing

**Product:** Meeting Room
**Type:** Bug
**Status:** Closed — Works as designed
**Date reported:** 2026-09-25
**Source:** [Meeting Room beta response](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/highlevel-meeting-room-response-2026-09-25.md)
**Impact:** Not assessed

## Observed
Screen-share audio was absent from a test recording. HighLevel clarified that browser audio is provided only when sharing a browser tab with audio enabled; whole-screen/app capture does not expose that stream.

## Why it matters
Keeping the browser limitation documented prevents the resolved misunderstanding from reappearing as an active defect.

## Expected
No product change is requested for the reported case. When shared audio is required, use browser-tab sharing with audio enabled; keep this issue only as resolved history.

## HighLevel response
Closed as works as designed for whole-screen sharing. Reopen only if a supported tab-share reproduction still omits audio.
