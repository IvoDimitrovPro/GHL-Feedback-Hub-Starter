# MR-209 — True full-screen viewing for shared screens

**Product:** Meeting Room
**Type:** UX
**Status:** Shipped
**Origin:** Ivo raised this at the 2026-04-14 HighLevel Product Town Hall and linked the “True Fullscreen in LIVE Sessions” idea. He explained that attendees on smaller displays could not see the full shared screen.

## Observed
The shared-screen view did not use the available display area, making presentations difficult to follow on smaller screens.

## Why it matters
Clients and attendees need to read the full shared material without the host changing their presentation.

## Expected
Let each attendee expand shared content to full screen independently.

## HighLevel response
A HighLevel representative replied, “Will fix this.” HighLevel support documentation dated 2026-08-27 now documents full-screen viewing and independent zoom controls for shared screens. This item is closed as shipped and should not remain in the active list.
