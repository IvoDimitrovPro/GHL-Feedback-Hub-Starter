# ZOOM-001 — Use the full display for shared-screen viewing

**Product:** Meeting Room
**Type:** UX
**Status:** Shipped
**Impact:** Not assessed
**Date reported:** 2026-04-14
**Source:** [Zoom feedback index](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/zoom-feedback-index-2026.md) — 2026-04-14 Product Town Hall

## Observed
Attendees on small displays could not see the whole shared screen.

## Why it matters
Shared-screen content can be unreadable on smaller displays when the viewer cannot use the full viewport.

## Expected
Allow shared-screen content to use the full available display/true fullscreen on supported clients so attendees can read the complete shared view.

## HighLevel response
HighLevel said it would fix this; documentation dated 2026-08-27 now confirms fullscreen and zoom controls. Shipped; keep out of Active.
