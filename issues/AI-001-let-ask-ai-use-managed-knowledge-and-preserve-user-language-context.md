# AI-001 — Let Ask AI use a managed Knowledge Base

**Product:** Ask AI
**Type:** Feature
**Status:** Acknowledged
**Impact:** High
**Date reported:** 2026-05-08
**Source:** [Zoom feedback index](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/zoom-feedback-index-2026.md) — 2026-05-08 Product Town Hall; 2026-06-15 Product Town Hall; 2026-08-06 Product Town Hall

## Observed
Ivo asked Ask AI to use agency-managed documents and Knowledge Base content across supported product areas.

## Why it matters
The assistant should give grounded answers using the agency's approved material.

## Expected
Allow Ask AI to reference a managed Knowledge Base and relevant uploaded documents in supported workflows.

## HighLevel response
HighLevel agreed that shared Knowledge Base access is a proper direction. Current Split View documentation describes page context on supported pages, but does not establish all requested sources.
