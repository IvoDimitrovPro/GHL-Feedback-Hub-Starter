# AI-006 — Preserve language preference and make page context controllable

**Product:** Ask AI
**Type:** UX
**Status:** New
**Impact:** High
**Date reported:** 2026-05-08
**Source:** [Zoom feedback index](https://github.com/IvoDimitrovPro/highlevel-product-feedback/blob/main/sources/zoom-feedback-index-2026.md) — 2026-05-08 Product Town Hall; 2026-06-15 Product Town Hall; 2026-08-06 Product Town Hall

## Observed
Ivo asked Ask AI to keep the language chosen by the user and to make the active page context clear and controllable.

## Why it matters
Language switching and hidden context make answers harder to trust and reuse with clients.

## Expected
Respect the user's selected language and clearly show or control page context across supported areas.

## HighLevel response
Ask AI Split View documentation describes page context on supported pages, but platform-wide language behavior and all requested context controls are not verified.
